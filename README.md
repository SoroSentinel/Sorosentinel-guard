# sorosentinel-guard

Pre-signing transaction analysis SDK for SoroSentinel (TypeScript):
`analyze(xdr, ctx)` called by a wallet before signing. Not a server.

This GitHub repo is currently named `Sorosentinel-core`; it holds the Guard
product described as `sorosentinel-guard` in the docs.

Status: Phase 0 stub. `make verify` is a no-op until the TypeScript workspace
lands (docs/project_structure.md §5 and §8 step 5).
